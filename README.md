# Rasam Demo

یک Demo ساده از محصول Rasam - پلتفرم تحلیل داده‌های صنعتی.

## پیش‌نیازها

- Python 3.8 یا بالاتر

## نصب و اجرا

1. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

2. اجرای برنامه:
```bash
streamlit run src/app.py
```

3. باز کردن مرورگر روی آدرس نمایش‌داده‌شده (معمولاً `http://localhost:8501`)

## ساختار پروژه

```
/workspace
├── src/
│   └── app.py          # نقطه ورود اصلی برنامه Streamlit
├── data/               # محل ذخیره داده‌ها (فعلاً استفاده نمی‌شود)
├── requirements.txt    # وابستگی‌های پروژه
└── README.md          # این فایل
```

## توضیحات

این نسخه فقط یک صفحه خوش‌آمدگویی ساده نمایش می‌دهد و هیچ قابلیت تحلیل داده، 
Database یا AI ندارد. هدف نشان دادن ساختار پایه و تمیز پروژه است.
